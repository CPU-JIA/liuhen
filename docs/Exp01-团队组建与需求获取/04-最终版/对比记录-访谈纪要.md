## 最终版形成方式

以人工版为骨架，编号用人工版的痛 / 要 / 不 / 问，每条后面括号注 LLM 的 P / N / C / O 编号，方便实验 2 两边都能追溯。吸收 LLM 两处：N12 单列，C3 保存期限先记为约束。人工版独有的 6 条全部保留：学委被问、学生看自己记录、评分态度、登记关联段落、老师不能比学生多看、试点公平。最终版放 04-最终版/访谈纪要.md。

## LLM 版的典型问题

- 它只看脚本，演练里临场加的 6 处它一个都没有。恰恰这 6 处里有本项目最重要的一条："学生自己看不到就是监控"。这说明 LLM 整理只能整理它看到的输入，现场的东西必须靠人记。
- 表格太整齐，原话的语气没了。"我不应该为证明自己是人付费"在 LLM 版里变成了"检测收费负担"。
- 把"声明不扣分"归为反对意见而不是要做的功能，方向对但不可执行。
- 优点也要写：P3 逐人约谈成本高，人工版排到最后，LLM 排第三，讨论后觉得 LLM 对。C3 保存期限它比我们记得准。

## 人工版的典型问题

- 把"配置一次自动执行"漏成了一句话，没单列。
- 把不抓聊天和不装监控合成一条，其实是两件事。
- 排序凭印象，痛12 明显排低了。
- 编号是自己起的，跟 LLM 版对不上，实验 2 得两套编号一起写。
