## 三、约束

| 编号 | 约束                                               | 来源                 | 说明                                           |
| ---- | -------------------------------------------------- | -------------------- | ---------------------------------------------- |
| C1   | 不得将学生作业文本上传外部公共 AI 平台             | 一-T 老师、二-J 老师 | 教育部指引要求；系统核心功能不依赖外部 AI 接口 |
| C2   | 系统记录仅为事实材料之一，最终认定由学院委员会作出 | 二-J 老师            | 法律责任边界                                   |
| C3   | 数据保存至学生毕业后一年，与论文材料保存要求对齐   | 二-J 老师            | 待教务确认                                     |
| C4   | 容器化部署、统一身份认证、有审计日志               | 二-J 老师            | 信息中心上线条件，Sprint 2 前回访确认          |
| C5   | 快照与登记由学生侧触发，不安装监控类客户端         | 三-小陈、四-小李     | 学生接受度前提                                 |
| C6   | 不自动抓取学生与 AI 的聊天记录，采用主动登记       | 四-小李              | 隐私边界                                       |
| C7   | 时间数据只记录不评价，不以写作时长推断作弊         | 三-小陈              | 避免新的误判                                   |
