## 画图规则

- 输入只有两样：`Exp02/04-最终版/用户故事卡.md` 和 `验收标准表.md`。每个实体、每个类都要能指到一张卡或一条验收。
- ER 图用 Chen 氏记法：实体矩形，属性椭圆，联系菱形，键属性下划线，弱实体双框，联系线上标 1 / N / M。不用鸟足记法，两种混着画老师会问。
- 类图先画领域类，再画服务类。四个手写算法（差分、归因、哈希链、规则引擎）各自是一个服务类，方法签名要写出来，实验 5 直接照着写。
- 手绘不求好看，求完整。画完拍照，录入版用 Mermaid 或 Graphviz 文本，录入时不许"顺手改进"，改进写到 03 目录。

## 常见错误

- 把 LLM 的表结构反过来画成 ER 图。顺序错了整份材料作废。
- 类图里只有实体没有服务，四个手写算法没地方放。
- ER 图上不标基数，SQL 里外键就是猜的。
- 优化只改命名不改结构。老师看的是你懂不懂增量存储、版本化、追加式写入这些事。
