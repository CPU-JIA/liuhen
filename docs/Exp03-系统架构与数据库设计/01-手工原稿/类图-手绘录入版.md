纸上批注（周浩然）：

- 组合（实心菱形）表示"随主体存在、不可单独删"，Snapshot、PasteEvent、Registration 都挂在 Work 下面，但 Work 本身也不删，所以整棵树只增不删。
- Snapshot 指向自己是"基于哪个快照的差分"，每 10 个来一个关键帧 fullText 不为空，其余 delta 不为空。
- Registration 指向自己是"改了哪一条"，改一次生成一条新的，旧的 status 变 VOIDED。
- Sprint 2 的类（ParagraphAttribution、EvidenceExport、Appeal、AuditLog）没画，实验 8 再画，免得现在画了到时候又改。

## 第 2 页：服务类（四个手写算法在这里）

```mermaid
classDiagram
    class MyersDiff {
        +diff(String a, String b) List~Edit~
        +apply(String base, List~Edit~ edits) String
        +lineDiff(String a, String b) List~LineChange~
    }
    class DeltaCodec {
        +encode(List~Edit~ edits) byte[]
        +decode(byte[] bytes) List~Edit~
    }
    class SnapshotService {
        +maybeCreate(Work w, SnapshotTrigger t) Optional~Snapshot~
        +reconstruct(Long snapshotId) String
        -shouldSnapshot(Work w) boolean
        -pickBase(Work w) Snapshot
    }
    class HashChainService {
        +append(String chainKey, byte[] payload) ChainLink
        +verify(List~ChainLink~ links) VerifyResult
        +head(String chainKey) String
    }
    class PolicyRuleEngine {
        +current(Long courseId, Long assignmentId) PolicyVersion
        +check(Registration r, PolicyVersion p) SceneCheck
        +needsReack(Long studentId, Long assignmentId) boolean
    }
    class DeclarationGenerator {
        +generate(Work w) Declaration
        -collect(Work w) List~Registration~
        -render(List~Registration~ rs, PolicyVersion p) String
    }
    class TimelineAssembler {
        +build(Long workId) Timeline
        -merge(List~Snapshot~, List~PasteEvent~, List~Registration~) List~TimelineItem~
    }
    class AccessControl {
        +can(AppUser actor, Action a, Object target) boolean
        -matrix Map~Role, Set~Action~~
    }
    class ForbiddenWords {
        +WORDS List~String~
        +scan(String text) List~String~
    }
    class AttributionService {
        +attribute(Snapshot s, List~PasteEvent~ p, List~ParagraphAttribution~ prev) List~ParagraphAttribution~
        -decay(double ratio, int editedChars, int totalChars) double
    }

    SnapshotService ..> MyersDiff
    SnapshotService ..> DeltaCodec
    SnapshotService ..> HashChainService
    DeclarationGenerator ..> PolicyRuleEngine
    DeclarationGenerator ..> HashChainService
    TimelineAssembler ..> SnapshotService
    TimelineAssembler ..> ForbiddenWords
    AttributionService ..> MyersDiff
```

纸上批注（周浩然）：

- MyersDiff 我手写，字符级和行级都要，行级给老师端高亮用。
- DeltaCodec 独立出来是为了实验 9 换编码方式不动别的。
- HashChainService 杨子航写，chainKey 是 "work:{id}:snapshot" 或 "work:{id}:registration"，两条链分开。
- AttributionService 是 Sprint 2 的，先把签名画出来占位，decay 是"粘贴后修改"的衰减规则。
- 没画 Controller 和 Repository，模板化的东西不占纸。
