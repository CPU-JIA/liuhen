# 本目录说明：实验 2 的 LLM 输出

> 生成工具：Claude Code（Claude Fable 5.1），2026-09-14。输入是实验 1 的 LLM 整理版访谈纪要（P、N、C、O 编号）与愿景说明 LLM 版。所有文件是"初稿"或"方法"，不是课程要求的手工草稿。

## 课程要求的正确顺序

指导书实验 2 的流程是：手动编写用户故事卡 → 编写验收标准 → 用 LLM 检查缺失、歧义、冲突 → 人工修改并保留对比 → 提交手工草稿、修改对比、最终版。

因此本目录的用法是：

1. 组员先按 `01-手工原稿/README-手工原稿产出指引.md` 手写故事卡与验收标准，不看本目录的初稿。
2. 手写完成后，用 `03-用户故事检查清单与LLM检查方法.md` 里的提示词把手写版交给 LLM 检查，检查结果原样存入本目录，命名 `04-LLM检查结果-针对手写版.md`。
3. 再打开 `01-用户故事卡-LLM初稿.md` 与 `02-验收标准-LLM初稿.md` 作为第二份对照，看手写版漏了什么、LLM 初稿多想了什么。
4. 对比与取舍写入 `03-对比与修改记录/`。

## 生成时使用的提示词（摘要）

1. "基于访谈纪要的 P、N、C、O 编号，按史诗组织用户故事，每个故事写作为、我想要、以便、优先级、Sprint、故事点、追溯编号，遵守 INVEST。"
2. "为 Sprint 1 的 Must 故事写验收标准，Given/When/Then，每条只验一件事，Then 必须可观察，数字要具体。"
3. "列出检查用户故事缺失、歧义、冲突的清单，并对上面的初稿自己做一次检查，找出至少 8 个问题。"
