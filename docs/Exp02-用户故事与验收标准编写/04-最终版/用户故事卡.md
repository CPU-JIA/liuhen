## ACC 账号

### US-ACC-01 老师开课、发作业

- 作为 任课老师
- 我想要 建一门课，在课下发作业、写截止时间
- 以便 学生知道往哪交、什么时候交
- Must　Sprint 1　来源 访谈一 p1
- 变更：课程码格式定为 6 位数字加大写字母，不区分大小写（A-12）

### US-ACC-02 学生用课程码进课

- 作为 学生
- 我想要 输一个课程码就进到老师的课里，看到作业列表
- 以便 不用老师一个个拉人
- Must　Sprint 1　来源 访谈四 p2
- 变更：无

### US-ACC-03 用学校账号登录

- 作为 学生或老师
- 我想要 用统一身份认证替换本地账号登录
- 以便 不用再记一个密码
- Should　Sprint 2　来源 无直接来源，信息中心待回访（C4）
- 变更：措辞由"提供登录"改为"替换本地登录"，消除 Must 依赖 Should（K-3）

### US-ACC-04 本地账号与名单导入

- 作为 任课老师
- 我想要 建课时上传学生名单生成本地账号，学生首次登录改密码
- 以便 Sprint 1 没有统一认证也能用起来
- Must　Sprint 1　来源 LLM 检查 M-1；访谈二 p3 J 老师说信息中心对接至少一个月
- 变更：新增

## RULE 规则

### US-RULE-01 老师定这门课的 AI 规则

- 作为 任课老师
- 我想要 在三档里选一档（禁止 / 需声明 / 鼓励），再勾选允许的场景（查资料、改语法、生成大纲、生成正文、生成代码框架、生成数据），也可自定义场景
- 以便 开学讲一次，之后系统替我重复
- Must　Sprint 1　来源 访谈一 p2
- 变更：档名改正式写法（A-5），口语版"不让用 / 用了要说 / 鼓励用"只作界面提示语备选；每次修改保留版本与时间（K-2）

### US-RULE-02 学生一进作业先看到规则

- 作为 学生
- 我想要 点开作业第一眼看到这门课的档位与允许场景，看完点"我已阅读"
- 以便 不用猜也不用问学委
- Must　Sprint 1　来源 访谈四 p1
- 变更：无

### US-RULE-03 老师写明评分态度

- 作为 任课老师
- 我想要 在规则里写一句评分态度，比如"如实声明不扣分"
- 以便 学生敢说真话
- Should　Sprint 1　来源 访谈一 p3
- 变更：无

### US-RULE-04 规则页可分享

- 作为 学委
- 我想要 复制这门课规则页的链接发到群里，未进课的同学也能看
- 以便 不用一个个回答"这门课能不能用"
- Could　Sprint 2　来源 访谈四 p1
- 变更：公开版只显示课程名与规则，不显示老师姓名与作业列表（K-4）

### US-RULE-05 作业级覆盖课程规则

- 作为 任课老师
- 我想要 为某次作业单独设一套规则，覆盖课程规则
- 以便 期末项目与平时作业规则不同
- Should　Sprint 2　来源 访谈一 p2；采纳 LLM 初稿 US-POL-02（M-7）
- 变更：从停车场落成卡

## WRK 写作区

### US-WRK-01 在系统里写，自动保存

- 作为 学生
- 我想要 直接在网页里写作业，停手几秒它自己存
- 以便 不用 Ctrl+S 也不怕丢
- Must　Sprint 1　来源 访谈三 p1
- 变更：断网保护边界定为 10 分钟、5000 字符（A-9）；上限 50,000 字符

### US-WRK-02 版本自动留存

- 作为 学生
- 我想要 系统每隔一段时间或我改得多了就自动存一版，我不用操作
- 以便 万一被怀疑，能拿出"我是一步步写出来的"
- Must　Sprint 1　来源 访谈三 p1、p2
- 变更：拍板"版本不可删"，理由是哈希链做了以后删一条整条链断（K-1）；间隔 10 分钟或 500 字符；增量存储小于全文之和 30%（A-4）

### US-WRK-03 大段粘贴时选来源

- 作为 学生
- 我想要 粘贴超过 100 字符时系统弹一下让我选来源（自己的其他文档 / AI 工具 / 网络资料 / 其他）
- 以便 当时顺手选了，交的时候不用回忆
- Must　Sprint 1　来源 访谈四 p2
- 变更：阈值由"80 字，约两行"改为 100 字符（A-3）

### US-WRK-04 导入 Word 作为一个版本

- 作为 学生
- 我想要 把在别处写好的 Word 上传，算作一个新版本并标"导入"
- 以便 习惯用 Word 也能留记录
- Should　Sprint 2　来源 访谈三 p1
- 变更：由 Sprint 1 挪到 Sprint 2，给 ACC-04 腾位置

### US-WRK-05 学生查看自己的时间线

- 作为 学生
- 我想要 看到系统给我留了哪些版本、哪些记录，和老师看到的一样多
- 以便 我心里有数，也确认它没在背后记别的东西
- Must　Sprint 1　来源 访谈三 p3、访谈一 p3
- 变更：名称由"我的记录"统一为"我的时间线"（A-6）；补空态（M-5）

## REG 登记

### US-REG-01 登记一次 AI 使用

- 作为 学生
- 我想要 用了 AI 之后点几下就登记完：工具、环节、用途、采用方式必选，版本、提示词、输出、核对方式可选
- 以便 几十秒搞定，不用最后补
- Must　Sprint 1　来源 访谈四 p2、p3
- 变更：拆出关联段落为 REG-03（A-1）；加版本与核对方式两个可选项（M-2）；采用方式枚举为直接采用 / 修改后采用 / 仅作参考 / 未采用（A-7）

### US-REG-02 修改登记保留历史

- 作为 学生
- 我想要 改或作废一条登记，系统把改之前的留下来
- 以便 我能纠错，老师也不会觉得我事后抹记录
- Should　Sprint 1　来源 访谈二 p2
- 变更：修改实现为追加新记录、旧记录标作废，为 Sprint 2 哈希链留路（K-7）

### US-REG-03 登记关联到段落

- 作为 学生
- 我想要 把一条登记关联到正文的一段或几段
- 以便 老师看得到哪段和哪次 AI 使用有关
- Should　Sprint 1　来源 访谈四 p3
- 变更：从 REG-01 拆出，依赖 REG-01

## DECL 声明

### US-DECL-01 提交时自动生成 AI 使用声明

- 作为 学生
- 我想要 点提交时系统把全部登记汇总成《AI 使用声明》，七要素齐全，格式对齐南京大学备案表

- 作为 学生

- Should　Sprint 1　来源 访谈一 p4

## TCH 老师端

### US-TCH-01 查看作业时间线

- 作为 任课老师
- 我想要 看一条时间线，版本、粘贴、登记按时间排在一起
- 以便 不用翻一堆截图
- Must　Sprint 1　来源 访谈一 p3

### US-TCH-02 两个版本对比高亮

- 作为 任课老师
- 我想要 选两个版本，增删用颜色标出
- 以便 看学生某一段时间到底改了什么
- Must　Sprint 1　来源 访谈一 p3
- 变更：无。周浩然认领差分算法手写

### US-TCH-03 只呈现事实

- 作为 任课老师
- 我想要 界面上没有"疑似""作弊""风险""AI 率"这类词和红色警告，也不出现任何基于写作时长的统计或评价
- 以便 判断权在我手里，学生也不会被吓得绕开系统
- Must　Sprint 1　来源 访谈一 p4、访谈三 p2
- 变更：验收文案改为"不存在汇总写作时长或据此评价的字段"，时间戳本身允许（K-5）；保留合并形态（A-2 判误报）

### US-TCH-04 段落来源标记与占比

- 作为 任课老师
- 我想要 每段标记为人写 / AI 粘贴 / 粘贴后修改，全文给三类占比
- 以便 看出哪些是学生消化过的
- Should　Sprint 2　来源 访谈一 p3
- 变更：无。实验 8 拆分细化，届时确认学生端同样可见

### US-TCH-05 全班一览

- 作为 任课老师
- 我想要 看一眼全班多少人登记了、常用哪些工具
- 以便 下次上课有针对性地讲
- Could　Sprint 2　来源 无直接来源，孟甲扮老师时提出
- 变更：无

## 不做的卡与理由

| 卡                         | 来自     | 理由                                                                |
| -------------------------- | -------- | ------------------------------------------------------------------- |
| 手动给版本打标签           | LLM 初稿 | 四场访谈没人提，好看但没人要                                        |
| 登记"追问与修正"           | LLM 初稿 | REG-01 的提示词与输出字段已能体现追问过程，不单独做（纪要 N9 放弃） |
| 时间线上加粗标出大幅改动   | LLM 初稿 | 变相的风险标记，与 TCH-03 精神相悖                                  |
| 让 AI 把登记总结成声明摘要 | 手写     | 系统不接外部大模型，实验 1 已定                                     |
| 手机端                     | 手写     | 时间不够                                                            |
| 老师给某个版本留言         | 手写     | 与主线无关                                                          |
| 统计每人写作时长           | 手写     | 被 TCH-03 直接否定                                                  |
| 微信推送                   | 手写     | 时间不够                                                            |
