# 小组代码走查记录

> 指导书要求"进行小组内代码走查"。走查会 2026-09-16 晚，线上，六人到齐，每人讲自己的核心代码 20 分钟，其余人对着验收标准与设计说明挑毛病。记录：张家森。只评代码不评人。

## 走查清单（每段代码都过一遍）

1. 这段代码对应哪条验收标准？没有对应的为什么存在？
2. 有没有任何"删除"？有就是错的。
3. 有没有任何时长统计或判定性文案？
4. 边界：空文本、5 万字符、emoji、同一秒两条记录。
5. 事务：抛异常会不会把该保存的东西回滚掉？
6. 权限：这个接口谁能调？对象归属查了没有？
7. 命名：变量名能不能让不写代码的人看懂？
