# 实验 5 Sprint 1 核心编码（人工实现业务逻辑）

**第 6 周 | 2 学时 | 设计型**

- 人工必做：手写核心算法与业务逻辑、组内走查
- LLM 可做：生成项目框架或基础代码

## 目录约定

| 目录 | 放什么 |
| --- | --- |
| 01-手工原稿 | 组员手写或手工整理的原始材料：笔记、草稿、手绘图照片 |
| 02-LLM输出 | LLM 生成的原始内容，原样保存，标注工具与时间 |
| 03-对比与修改记录 | 人工版与 LLM 版的对比、采纳与否的理由、修改前后差异 |
| 04-最终版 | 提交给老师的最终材料与本实验的六段式实验报告 |

## 提交材料清单

- [x] 项目代码
- [x] 核心算法说明
- [x] 人工修改记录
- [x] 小组代码走查记录
- [x] 实验报告（实验目的、实验内容、实验过程、实验结果、问题与解决、个人体会）
