# 本目录说明：实验 5 的 LLM 输出

> 生成工具：Claude Code（Claude Fable 5.1），2026-09-15 晚到 2026-09-16，操作人孟甲。按指导书"使用 LLM 生成项目框架或基础代码"，LLM 只生成骨架，核心算法与业务逻辑由组员手写（清单见 `01-手工原稿/README`）。

## LLM 生成了什么

| 范围     | 文件                                                                                                              | 后来怎么处理                             |
| -------- | ----------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| 构建     | project/backend/pom.xml、application.yml、LiuhenApplication.java                                                  | yml 改了 3 处，见人工修改记录            |
| 实体     | account、policy、work、registration、declaration 五个包里的 @Entity 类与枚举                                      | 按实验 3 的 schema 逐字段核对，改了 6 处 |
| 仓库     | 全部 *Repository 接口                                                                                             | 补了 4 个查询方法                        |
| 安全骨架 | SecurityConfig、JwtAuthFilter、JwtService、CurrentUser                                                            | SecurityConfig 改了放行范围              |
| 接口骨架 | AuthController、CourseController、AssignmentController、WorkController、RegistrationController 的路由与参数记录类 | 方法体全部由手写 Service 填充            |
| 异常处理 | ApiExceptionHandler                                                                                               | 补了 403 统一文案与请求体不可读          |
| 前端骨架 | package.json、vite.config.ts、tsconfig、index.html、main.ts、router.ts、api.ts、styles.css、七个页面的布局与表格  | 编辑器的保存、缓存、粘贴逻辑由丁浩然手写 |
| 测试骨架 | 四个测试类的类声明与第一条用例                                                                                    | 其余用例手写                             |

## 原样保存的生成物

`骨架快照/` 目录保存三个后来被明显改动的文件的 LLM 原版，供对比：

- `application-LLM版.yml`
- `SecurityConfig-LLM版.java`
- `ApiExceptionHandler-LLM版.java`

其余生成物与仓库里的最终文件差异只在补充方法或字段，对比记录里逐条列出，不再保存原版。

## 提示词原文（骨架）

```
按下面的 MySQL 建表脚本与设计说明，生成 Spring Boot 3.5 项目骨架：Maven pom（Java 25，web、data-jpa、security、validation、flyway、mysql、jjwt、poi），
application.yml，JPA 实体与仓库接口（字段名与列名一一对应，枚举用 STRING），JWT 无状态安全配置骨架，按史诗分包的 Controller 路由骨架（方法体留空抛 UnsupportedOperationException），
统一异常处理骨架。不要实现任何业务逻辑，不要引入差分或哈希库。
```

```
生成 Vue 3 + Vite + TypeScript 前端骨架：路由（登录、改密、课程、作业、编辑器、时间线、声明），axios 封装（Bearer 令牌、401 跳登录），
七个页面的布局与表格，不含任何业务逻辑，编辑器只放一个 textarea。样式不用红色表达来源信息。
```

## 明确没有让 LLM 做的

- 没有让它写 MyersDiff、DeltaCodec、HashChainService、PolicyRuleEngine、SnapshotService、DeclarationService、AccessControl。
- 没有让它写前端的自动保存、断网缓存、粘贴检测。
- 没有让它写测试用例的断言（第一条除外）。
- 没有让它修 bug。三处 bug 的定位与修复在人工修改记录里。
