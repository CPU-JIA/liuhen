## 二、回归用例初稿的修正

R-2 的回归用例初稿在 `02-LLM输出/01-时间线页测试初稿/`。跑第一次：

```
 ❯ src/views/TimelineView.test.ts (3 tests | 1 failed)
   × 时间线页 > AC-PERM-01-1 没有权限时页面提示无权限，而不是显示空态
     → undefined
   ✓ 时间线页 > AC-WRK-05-3 新作业没有记录时只显示空态一句话
   ✓ 时间线页 > AC-TCH-01-3 只有版本、粘贴、登记三类条目，默认选中最后两版对比
 FAIL  ... AC-PERM-01-1 ...
{ response: { status: 403, data: { code: 403, message: '没有权限' } }, stacks: [] }
```

失败输出里没有断言错误，只有那个拒绝对象本身，说明是未处理的 rejection 被记到了这条用例头上。丁浩然做了三个变体二分：去掉 `beforeEach` 里的 `mockReset()` 就过；只留第一条用例不过；去掉两个 `expect` 也不过。结论是 vitest 3 的 `mockReset()` 与随后 `mockRejectedValue` 的组合会多出一个没人接的拒绝。改法：不在 `beforeEach` 里 reset，每条用例自己设桩（每条都会覆盖实现，reset 本来就是多余的），并在文件里写了一行注释。EditorView.test.ts 没踩到是因为它从来没用过 `mockReset`。
