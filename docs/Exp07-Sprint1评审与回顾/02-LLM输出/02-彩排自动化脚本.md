## 片段三：造 50 版 10 登记（李思远，走接口）

# 按改动量触发：每次追加一段 500+ 字符再 PUT 全文，直到 snapshotCreated 累计 50 次；再 POST 10 条登记
text = ""
while snaps < 50:
    text += f"\n\n第 {i} 段。" + ("这是第 %d 段的正文，用来演示时间线在五十个版本下的渲染速度。" % i) * 20
    r = call("PUT", f"/api/works/{W}/text", {"text": text})
