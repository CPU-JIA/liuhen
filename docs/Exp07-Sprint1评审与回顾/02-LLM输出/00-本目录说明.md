# 本目录说明：实验 7 的 LLM 输出

> 指导书对本实验写的是"LLM 可做：无"。演示脚本、问答记录、回顾改进项、述职、实验报告都是人写的，没有让 LLM 起草或润色。本目录记的是评审准备期间两处工具性的使用，以及一份回归用例初稿，按课程"保留 LLM 输出"的要求存档。生成工具：Claude Code（Claude Fable 5.1），操作人孟甲。

## 明确没有让 LLM 做的

- 演示脚本的步骤、说的话、彩排后的改动。
- 评审课上的问答记录与整理。
- 回顾会的便利贴、投票、改进项、负责人与验证方式。
- 六份述职。
- 实验报告正文。
- 三个彩排 bug 的判断与修法。

## 提示词原文

移列脚本：

```
仓库里已有 tools/create-sprint1-issues.ps1 和 tools/add-sprint1-issues-to-board.ps1。写第三个脚本 update-sprint1-board.ps1：
参数 -Week 5..8 表示"第 N 周结束时"。脚本里放一张表：任务编号 | 计划周 | 实际完成周 | 实际小时（我来填）。
对每个带 sprint-1 标签的 Issue：实际完成周 <= N 的任务行勾选并在行尾追加"实际 Nh，第 N 周完成"；
卡片全部勾完就关闭 Issue 并把看板 Status 置"完成"；有任务完成或计划周 <= N 的置"进行中"；否则"待办"。
可重复运行，可回退（重开 Issue）。gh 调用带重试，输出 UTF-8。加 -DryRun。
```

彩排自动化：

```
按下面 30 步在 http://localhost:5173 上走一遍，每个关键页面截图到指定目录，文件名带序号。
粘贴事件 jsdom 之外要用 DataTransfer 构造 ClipboardEvent 再手动插入文本。每步把页面上的关键文案返回给我核对。
```

回归用例：

```
给 TimelineView.vue 写 vitest：(1) api.get 返回 403 时页面显示"没有权限"且不显示"还没有记录"；(2) 空数组时显示空态一句话；
(3) 三类条目各一条时标签顺序与默认选中的两个版本号。桩的写法与 EditorView.test.ts 一致。
```
